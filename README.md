# List do Mikołaja 🎄

Interaktywny, animowany list do Mikołaja od dzieci.

1. Na zimowym tle rysuje się choinka i zaczyna padać śnieg.
2. Pojawiają się girlandy i bombki, a na końcu gwiazda z blikiem światła.
3. Po kliknięciu „Przeczytaj list do Mikołaja od dzieci” list pisze się odręcznie.
4. Na końcu pojawiają się dwa prezenty: **Pierwszy** i **Drugi**. Kliknięcie otwiera link w nowej karcie.

## Pliki

- `index.html` – struktura strony
- `style.css` – wygląd
- `script.js` – animacje; **na górze pliku jest sekcja `CONFIG`** z linkami, podpisem i treścią listu

## Publikacja na GitHub Pages

1. Wrzuć pliki do repozytorium (np. `list-do-mikolaja`), tak aby `index.html` leżał w katalogu głównym.
2. Wejdź w **Settings → Pages**.
3. W „Build and deployment” wybierz **Deploy from a branch**, gałąź `main`, folder `/ (root)` i zapisz.
4. Po chwili strona będzie dostępna pod adresem `https://<twoj-login>.github.io/list-do-mikolaja/`.

Czcionka odręczna (Caveat) jest ładowana z Google Fonts, więc strona potrzebuje internetu, żeby wyglądała w pełni.
